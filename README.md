# Nollywood Creative Minds Forum (NCMF) — Official Web Platform

> **“Optimizing Potentials”** · Est. 2015 · CAC Registered  
> The official web portal for Nigerian film practitioners, featuring online membership onboarding, interactive public directory, programmes archive, projects showcase, and secretariat administration CMS.

---

## 🌟 Overview & Key Features

Designed to Google/Apple level craft and polish with cinematic Nollywood elegance (deep midnight obsidian, rich warm gold `#d49526`, glassmorphism, fluid micro-interactions, responsive mobile layout).

### 1. Public Visitor & Filmmaker Journey
- **Instant Clarification of Core Questions (First-Time Visit)**:
  1. *What does the forum do?* (Mentorship, masterclasses, collaborative short & feature film production, safe set advocacy).
  2. *What do I gain by joining?* (Comprehensive welfare package, casting pipelines, masterclass access, directory visibility).
  3. *How do I apply?* (Transparent online application, subsidized ₦20,000 fee, instant unique tracking code).
- **Flagship Programme Spotlight**:
  - Showcases the annual *In Pursuit of Better* National Summit & Creative Merit Awards at **Four Points by Sheraton, Victoria Island, Lagos**.
- **Signature Productions Showcase**:
  - DStv hit feature film ***Perfect for Divorce*** produced under President Ijeoma Richards.
  - Festival-winning short film ***Bottled Up*** (British Council FilmLab Africa, Best Short Film at Kaduna International Film Festival) by Head of Media Tolulope Odebunmi.
  - Original stage production ***Mentality: What Men Don't Say*** (Lagos Fringe Festival).
- **Official Media Gallery**:
  - Captioned, dated, high-resolution original photographic archives from Four Points by Sheraton ceremonies, panel discussions, and official leadership portraits with interactive modal lightboxes.

### 2. Automated Membership Onboarding
- **Interactive Application Form**: Full Name, Email, WhatsApp Phone, Creative Discipline, Industry Experience, State/Chapter, Showreel/Portfolio URL, IMDb link, and Statement of Purpose.
- **Automated Duplicate Prevention**: Re-submissions with the same email or phone number are safely blocked and existing reference numbers returned.
- **Reference Number Generation**: Issues instant tracking codes (e.g. `NCMF-2026-XXXX`).
- **Confetti Celebration**: Celebratory feedback on completed submission.
- **Directory Opt-In Consent**: Complies with the PRD's privacy model where applicants explicitly choose whether their approved profile should appear in the public directory.

### 3. Public Member Directory (Privacy & Consent Enforced)
- Displays only approved, opted-in practitioners.
- Search by name, keywords, or creative discipline (Actors, Directors, Producers, Screenwriters, Cinematographers, Editors, Media).
- Safe communication: Inquiries for casting or co-production are routed through the Secretariat without exposing personal phone numbers or home addresses.

### 4. Interactive WhatsApp Live Chat Widget
- Floating widget on the bottom-right corner.
- Automated instant answers to common questions (Membership application, Annual Summit at Four Points, Projects, Secretariat lines).
- One-click deep link to official WhatsApp: `+234 811 805 0555` (`08118050555`).

### 5. Secretariat Reviewer & CMS Portal (`/admin` or Reviewer Button)
- **Vetting Queue**: Retrieve applications, inspect applicant statements and IMDb links, record decisions (**Approve & Enrol**, **Mark Under Review**, **Reject**), and add secretarial evaluation notes.
- **Automatic Directory Synchronization**: Approving an application that opted into the directory automatically enroles the member into the live public directory.
- **Events CMS**: Designated editors can publish new upcoming events or archive past ones with conditional registration links (as mandated in the PRD, booking buttons only appear when valid links exist).
- **CSV Data Export**: One-click download of all membership applications for committee records.

## 🚀 Quick Start & Development

```bash
# 1. Install dependencies
npm install

# 2. Start development server (running on port 3000)
npm run dev

# 3. Production build
npm run build

# 4. Preview production build
npm run preview
```

The production bundle is generated in `dist/` with static assets, images, and HTML ready for deployment on any dedicated server, Apache, Nginx, or Vercel/Netlify.
